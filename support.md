# Support

Where to ask questions and report bugs depends on whether the module is free or premium.

## Free modules

Report bugs on the module's GitHub issues page:

- [5e Item Importer](https://github.com/GnollStack/5e-Item-Importer/issues)
- [Show of Hands: Targeting & Cursors](https://github.com/GnollStack/Show-Of-Hands/issues)
- [Squad Combat Initiative](https://github.com/GnollStack/Squad-Combat-Initiative/issues)
- [The Sound of Silence](https://github.com/GnollStack/The-Sound-of-Silence/issues)

You can also ask questions in the public channels of the [Bakshi's Bazaar Discord](https://discord.gg/tcdYk54fxC).

## Premium modules

Help and bug reports for 5e Activity Importer, Custom Currency 5e, FileSmith, Immersive Vision FX and Traffick go through the [Bakshi's Bazaar Discord](https://discord.gg/tcdYk54fxC). Patrons get priority support in the patron-only channels, without guaranteed response times.

## What to include in a bug report

- Your Foundry VTT version, game system and version, and module version
- Other active modules that might be involved
- The steps that cause the problem, what you expected, and what happened instead
- Any errors from the browser console (press F12), and a screenshot or short clip if it helps
